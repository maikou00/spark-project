# 开发环境搭建

## 前置条件

- Docker Desktop 已安装并运行
- 宿主机已安装 `mysql` 客户端（可选，也可通过 `docker exec` 连接）

---

## 一、MySQL

### 启动

```bash
docker run -d \
  --name mysql-dev \
  -p 3307:3306 \
  -e MYSQL_ROOT_PASSWORD=root123 \
  -e MYSQL_DATABASE=spark_test \
  mysql:8.0
```

### 连接信息

| 属性 | 值 |
|------|-----|
| Host | `localhost` |
| Port（宿主机） | `3307` |
| JDBC URL | `jdbc:mysql://localhost:3307/spark_test` |
| 用户 | `root` |
| 密码 | `root123` |
| 数据库 | `spark_test` |
| 驱动 | `com.mysql.cj.jdbc.Driver` |

### 常用命令

```bash
# 宿主机连接
mysql -uroot -proot123 -h127.0.0.1 -P3307 spark_test

# 容器内连接
docker exec -it mysql-dev mysql -uroot -proot123 spark_test

# 查看日志
docker logs -f mysql-dev
```

---

## 二、ClickHouse

### 启动

```bash
docker run -d \
  --name clickhouse-dev \
  -p 8123:8123 \
  -p 9000:9000 \
  -e CLICKHOUSE_USER=default \
  -e CLICKHOUSE_PASSWORD=ck123 \
  clickhouse/clickhouse-server:24.3
```

### 连接信息

| 属性 | 值 |
|------|-----|
| HTTP Host | `localhost` |
| HTTP Port | `8123` |
| Native Port | `9000` |
| JDBC URL | `jdbc:clickhouse://localhost:8123` |
| 用户 | `default` |
| 密码 | `ck123` |
| 批量写入大小 | `10000` |

### 常用命令

```bash
# HTTP 查询
curl -u default:ck123 "http://localhost:8123/?query=SELECT+1"

# 容器内 client
docker exec -it clickhouse-dev clickhouse-client -u default --password ck123

# 查看日志
docker logs -f clickhouse-dev
```

## 三、Doris

### 启动

```bash
cd spark-project/docs
docker compose up -d
```

### 停止

```bash
cd spark-project/docs
docker compose down          # 保留数据卷
docker compose down -v       # 删除数据卷（重置集群）
```

### 架构

```
┌──────────────────────────────────────────┐
│                  Docker                    │
│                                           │
│  ┌─────────────┐    ┌──────────────────┐  │
│  │  doris-fe   │◄──►│    doris-be      │  │
│  │  (FE 节点)  │    │   (BE 节点)      │  │
│  │  172.20.0.2 │    │   172.20.0.3     │  │
│  └──────┬──────┘    └──────────────────┘  │
│         │                                  │
│   ┌─────┴─────┐                            │
│   │ :8030 HTTP │                            │
│   │ :9030 MySQL│                            │
│   └───────────┘                            │
└──────────────────────────────────────────┘
```

### 连接信息

| 属性 | 值 |
|------|-----|
| FE HTTP | `localhost:8030` |
| MySQL 协议 | `localhost:9030` |
| JDBC URL | `jdbc:mysql://localhost:9030` |
| 用户 | `root` |
| 密码 | （无） |
| 驱动 | `com.mysql.cj.jdbc.Driver` |
| 批量写入大小 | `10000` |

### 常用命令

```bash
# 启动
cd spark-project/docs && docker compose up -d

# 停止
cd spark-project/docs && docker compose down

# MySQL 协议连接
mysql -uroot -h127.0.0.1 -P9030

# 容器内连接
docker exec -it doris-fe mysql -uroot -P9030 -h127.0.0.1

# 查看 FE 状态
docker exec doris-fe mysql -uroot -P9030 -h127.0.0.1 -e "SHOW FRONTENDS\G"

# 查看 BE 状态
docker exec doris-fe mysql -uroot -P9030 -h127.0.0.1 -e "SHOW BACKENDS\G"

# 查看日志
docker logs -f doris-fe
docker logs -f doris-be

# 重置集群（清空所有数据）
cd spark-project/docs && docker compose down -v && docker compose up -d
```

### 端口说明

| 端口 | 服务 | 用途 |
|------|------|------|
| `8030` | FE HTTP | Web UI、Stream Load |
| `9030` | FE MySQL | MySQL 协议查询 |
| `9010` | FE 内部 | FE 节点间通信 |
| `8040` | BE HTTP | BE Web UI |
| `9050` | BE 内部 | 心跳服务 |
| `9060` | BE 内部 | BE RPC |
| `8060` | BE 内部 | BRPC |
